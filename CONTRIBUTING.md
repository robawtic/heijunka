# Contributing to Heijunka

Thank you for your interest in contributing to Heijunka! Your help is vital to the project’s success. This document outlines the process for reporting issues, submitting pull requests, and participating in the community.

---

## 📋 How to Contribute

### 1. Reporting Issues

- **Search first**: Please check the [issue tracker](../../issues) to see if your issue has already been reported.
- **Provide details**: If you’re reporting a bug, include steps to reproduce, your environment, and relevant logs or screenshots.
- **Feature requests**: Clearly describe the use case and any ideas you have for implementation.

### 2. Submitting Pull Requests

- **Fork the repository** and create your branch from `main`.
- **Write clear code** and follow existing code style and conventions.
- **Test your changes** before submitting a PR.
- **Describe your changes** in the pull request template, and link any related issues.

### 3. Community & Code of Conduct

- Be respectful, open-minded, and constructive.
- We follow the [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md) to foster a welcoming community.

### 4. Need Help?

- Use [GitHub Discussions](../../discussions) for questions or to connect with the community.
- For security issues, **do not open a public issue**. Please follow the process in [SECURITY.md](SECURITY.md).
