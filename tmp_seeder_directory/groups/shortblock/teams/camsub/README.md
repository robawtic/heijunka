# Camsub Team

This directory contains data and configuration files for the Camsub team in the Shortblock group of the Powertrain department.

## Team Description

The Camsub team is responsible for camshaft sub-assembly operations. They prepare and assemble camshaft components, including cam lobes, bearings, and related timing components before integration into the engine.

## Workstations

The Camsub team operates the following workstations:

1. **CS010** - Initial camshaft preparation and component staging (loading job)
2. **CS020** - Cam lobe installation and timing setup (key skill job)
3. **CS030** - Final assembly and quality verification

## Team Structure

The team typically consists of:
- 1 Team Leader
- 1 Backup
- Several Associates

## Scheduling Considerations

- Key skill jobs (CS020) require specific training and certification
- Employees should rotate through different workstations to maintain skills
- Timing accuracy is critical, so quality checks are emphasized
- The team's output directly affects engine timing and performance
