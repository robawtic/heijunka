# Shortblock Team

This directory contains data and configuration files for the Shortblock team in the Shortblock group of the Powertrain department.

## Team Description

The Shortblock team is responsible for the initial assembly of the engine block, including pistons, crankshaft, and related components. This forms the foundation of the engine assembly process.

## Workstations

The Shortblock team operates the following workstations:

1. **SB010** - Initial block preparation and component loading (loading and heavy job)
2. **SB020** - Piston and connecting rod installation
3. **SB030** - Crankshaft installation and torque application (key skill job)

## Team Structure

The team typically consists of:
- 1 Team Leader
- 1 Backup
- Several Associates

## Scheduling Considerations

- Heavy jobs (SB010) should be rotated among employees to prevent fatigue
- Key skill jobs (SB030) require specific training and certification
- Employees should rotate through different workstations to maintain skills
- The team's work feeds directly into other assembly processes, so consistent output is critical
