# Security Policy

## Supported Versions

At this time, the Heijunka project does **not** maintain formal versioned releases or an official version support policy.  
**All code in this repository is supported on a best-effort basis.**  
If you are using Heijunka in production or critical environments, please ensure you are tracking updates and applying fixes as needed.

---

## Reporting a Vulnerability

If you discover a security vulnerability in Heijunka, please help keep the project and its users safe by following these steps:

1. **Private Disclosure First**  
   Please do not publicly disclose vulnerabilities (such as in issues or pull requests).

2. **How to Report**  
   Report security issues by emailing [robawtic@gmail.com](mailto:robawtic@gmail.com) with:
   - A detailed description of the vulnerability
   - Steps to reproduce, if possible
   - Potential impact

3. **Response Process**
   - You will receive an acknowledgment within **48 hours**.
   - The issue will be investigated as a priority.
   - You will receive updates at least once per week until resolution.
   - If a fix is required, we will coordinate with you for responsible disclosure and optional credit in release notes or acknowledgments.

---

Thank you for helping improve the security of Heijunka!
